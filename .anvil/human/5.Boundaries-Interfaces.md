# 5. Boundaries and Interfaces

These are the ways the outside world touches ADK: a CLI, an HTTP/WebSocket server, Python extension points and configuration.

## CLI (`adk`, `pyproject.toml:408`, `cli/cli_tools_click.py`)

| Command | Purpose | Line |
|---|---|---|
| `adk create` | Scaffold an agent project | 810 |
| `adk run` | Interactive terminal run | 984 |
| `adk eval` / `eval_set` | Run and manage evaluations | 1318 / 1709 |
| `adk optimize` | Agent optimization | 1579 |
| `adk web` | Dev server with UI | 2209 |
| `adk api_server` | Production-style API server | 2342 |
| `adk deploy cloud_run/docker/agent_engine/gke` | Deployment | 2489-3130 |
| `adk migrate session` | Session DB migration | 2729 |
| `adk telemetry`, `adk conformance` | Telemetry toggle, conformance tests | 438, 600 |

## HTTP API (`cli/api_server.py`)

| Route | Line |
|---|---|
| `GET /health`, `GET /version` | 1523, 1527 |
| `GET /list-apps` | 1619 |
| `GET /apps/{app_name}/app-info` | 1630 |
| Session CRUD under `/apps/{app_name}/users/{user_id}/sessions/...` (POST, DELETE, PATCH) | 1691-1758 |
| Memory under `/apps/{app_name}/users/{user_id}/memory` | 2001 |
| `POST /run` | 2047 |
| `POST /run_sse` (streaming) | 2140 |
| `WS /run_live` (bidirectional) | 2324 |
| `POST /agent-identity/finalize` | 1543 |

`cli/dev_server.py` adds `/dev/apps/{app}/...` for debug traces, graph building, tests and telemetry config (e.g. `:914`, `:944`, `:587`); `cli/_dev_deploy.py` adds deploy endpoints (`:971`).

## Python extension points
`BaseAgent`, `BaseNode`, `BaseTool`/`BaseToolset`, `BaseLlm` (registered in `models/registry.py`), `BaseSessionService`, `BaseMemoryService`, `BaseArtifactService`, `BasePlugin`.

## Config and external protocols
- Agents may be declared in YAML (`agents/*_config.py`, `agents/config_schemas/`).
- `.env` loading via `python-dotenv`; service URIs resolved by `cli/service_registry.py`.
- MCP (`tools/mcp_tool/`), A2A (`a2a/`), OpenAPI tools (`tools/openapi_tool/`), and cloud integrations (`integrations/`).
